# Velo — циферблат и поле данных для Garmin fēnix 8 / fēnix 9

Два Connect IQ приложения в одном репозитории:

| Папка | Тип | Что делает |
|---|---|---|
| `watchface/` | циферблат | Экран-колесо: обод — прогресс шагов, спицы — часовые метки, «ниппель» — секунды. Время, дата, пульс, батарея, шаги. На AMOLED в always-on только тусклое время и дата. |
| `ridefield/` | поле данных | «Вело заезд»: добавляется на экран велотренировки. Скорость, таймер, дистанция, пульс, каденс, средняя, набор высоты, мощность. Справа анимированный велосипедист: колёса крутятся по дистанции, шатуны по каденсу, дорога бежит. Стоим — всё замирает. Уклон (по высоте и дистанции) наклоняет дорогу с велосипедом, от 5 % подъёма райдер встаёт на педали, от 5 % спуска группируется. Пульс красится по велосипедным зонам профиля, номер зоны в подписи. |

Почему тренировка — отдельное поле данных, а не режим циферблата: во время
записанной активности Garmin не показывает циферблат, экран занимает
приложение активности. Поля данных Connect IQ обновляются раз в секунду,
так что анимация идёт с шагом в кадр в секунду. Колёса и дорога шагают по
скорости, шатуны по каденсу, независимо (на накате колёса крутятся, ноги
стоят). Шаг за кадр растёт с реальной величиной, но держится меньше
полуоборота, иначе при 1 кадре/с вращение читается назад (стробоскоп).
Оранжевый катафот на ободе показывает полный оборот колеса.

## Устройства

fēnix 8 (43 / 47 / 51 мм, Solar 47 / 51, Pro), fēnix 9 (43 / 47 / 51 мм,
Pro 43 / 47 / 51, Pro Solar 47 / 51). Список — в `*/manifest.xml`.

## Сборка

Нужен Connect IQ SDK (ставится через SDK Manager, он же скачивает
описания устройств) и ключ разработчика в `~/.Garmin/ConnectIQ/developer_key`:

```bash
openssl genrsa -out developer_key.pem 4096
openssl pkcs8 -topk8 -inform PEM -outform DER -in developer_key.pem -out ~/.Garmin/ConnectIQ/developer_key -nocrypt
```

```bash
./build.sh watchface fenix847mm   # .prg одного приложения под одно устройство
./build.sh ridefield fenix947mm
./run.sh ridefield fenix847mm     # собрать и запустить в симуляторе
./release.sh watchface            # .iq для магазина (все устройства)
```

Прошивка на часы по USB: `bin/<app>-<device>.prg` → `GARMIN/Apps/` на часах.
Поле данных затем добавляется в настройках велотренировки:
Настройки → Экраны данных → Добавить → Connect IQ → Velo Ride.
